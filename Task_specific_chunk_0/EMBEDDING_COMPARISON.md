# Embedding and Chunk Comparison

## Source PDFs

- `ADHD.pdf`
- `parenting2015.pdf`

## Embedding models

- `JinaSmallEmbedding`: calls `jina-embeddings-v2-base-en` through the Jina embeddings API when `JINA_API_KEY` is available.
- `TfidfEmbedding`: local corpus-aware TF-IDF model used as the offline baseline.

If `JINA_API_KEY` is not set, `JinaSmallEmbedding` automatically uses the TF-IDF fallback so the notebook and tests still run offline.

## Evaluation questions

1. What recommendations did the committee make to ensure responsible use of ADHD medication?
2. How can parents create better home and school environments for a child with ADHD?
3. What discipline methods should parents learn for children with ADHD?

## Ground truth citations

- Q1: `ADHD.pdf:p46`
- Q2: `parenting2015.pdf:p1`
- Q3: `parenting2015.pdf:p3`
